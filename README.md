# VOIDSTORM AEGIS-7 v6 · 异构首领

单角色 HTML / Three.js 生存游戏。完整解压后，在 Mac 或 Windows 双击 index.html 即可开始；也可以使用 start_mac.command / start_windows.bat。所有运行依赖与素材均在本地，不使用 CDN，不需要安装开发工具。

手机请用浏览器打开部署后的地址。文件管理器的 HTML 预览可能不支持完整游戏功能。

## 操作

- WASD / 方向键：移动，主武器自动攻击。
- T：切换鼠标手动瞄准 / 自动瞄准。
- 全屏按钮 / F：进入或退出全屏。全屏包含 HUD、升级界面与虚拟摇杆。
- 不支持 Fullscreen API 的浏览器会明确提示；手机可尝试“添加到主屏幕”。这不等同于所有移动浏览器都支持原生全屏。
- E：Lv3 解锁棱镜壁垒。35% 护盾，3 秒拦截弹体与脉冲伤害，结束反击；初始冷却 12 秒。
- R：Lv6 解锁离子超载。击杀充能至 100% 释放追踪齐射、轨道打击、终末冲击。
- ESC / 暂停按钮：暂停。打开图谱、升级界面时也会暂停。
- 鼠标 / 触屏 / 数字键 1、2、3：选择升级卡。手机面板可以滚动到第三张卡。
- 手机自动显示移动、瞄准摇杆与技能按钮。

## v6 卡池与进化

卡池从 12 种战斗技能收敛到 8 种：能量步枪、回旋磁刃、反物质雷环、雷链矩阵、轨道信标、灼热离子矢、护航无人机、近域辐射场。保留投射物、回旋、地雷、连锁电击、轨道轰击、持续灼烧、召唤物、近身光环等差异机制。

旋风切割环、回响刃轨、涡旋脉冲器、湮灭协议已退出卡池。旧机制源码保留供以后开发，不会在正常抽卡中出现。

最多 5 个战斗技能（含主武器）、6 种属性。技能最高 Lv5；**所有局内属性最高 Lv3，达到 3/3 后不再出现，不会抽成 4/3。** 局外研究有独立的 Lv10 上限。

| 技能 | 进化所需属性 |
|---|---|
| 能量步枪、护航无人机 | 超频核心 Lv3 |
| 反物质雷环、灼热离子矢 | 聚变增幅器 Lv3 |
| 雷链矩阵、近域辐射场 | 重型装甲板 Lv3 |
| 回旋磁刃 | 矢量推进器 Lv3 |
| 轨道打击信标 | 量子瞄准镜 Lv3 |

- 技能 Lv5 + 对应属性 Lv3 后，每次抽卡优先提供一张已就绪进化卡；需要选中后才完成进化。
- 已进化的技能从卡池移除；满构筑后仍有三张不同的战术收益卡。
- 每逢等级为 3 的倍数，若没有就绪进化，至少提供一张已装备技能的升级或配套属性卡。
- 属性槽满且缺配套时，可出现“配套置换”：换掉一个不参与当前未进化技能配方的属性，换入所需属性 Lv1。卡上会写明被替换的属性；不增加槽位，也不消耗货币。
- 普通卡权重 1，已装备技能升级 1.35，配套新技能/属性 1.25，置换卡 1.5；权重不叠加。三选一仍然保留随机性。
- 进化图谱实时显示每条配方的进度与所缺条件。
- 升级立即回满生命；多级经验逐次弹出卡牌。经验晶体保留捕获、加速旋入、拖尾与吸收爆点。

## 机库研究

独立研究面板，10 条路线，每条最高 Lv10。单次价格为 90 + 当前等级 × 90 CR。已有伤害、生命、速度、磁吸升级及货币自动继承。

| 研究 | 每级效果 |
|---|---|
| 火控增幅 | 永久伤害 +4% |
| 装甲扩容 | 最大生命 +5% |
| 推进校准 | 移速 +2.5% |
| 回收磁场 | 拾取范围 +8% |
| 冷却回路 | 攻击与 E 冷却 -2% |
| 复合防护 | 伤害减免 +1.5% |
| 弱点分析 | 暴击率 +1.5% |
| 自愈纳米群 | 每秒回复 0.08% 最大生命 |
| 数据学习 | 经验获取 +3% |
| 离子蓄电池 | R 击杀充能 +5% |

局外研究只能在机库购买；不足货币与满级按钮会禁用。局内属性与研究的减伤合计封顶 58%，冷却系数最低 0.35。

AEGIS-7 被动“自适应核心”仍保留：每 12 次击杀获得 10% 护盾、4 秒内伤害 +15%；再次触发刷新持续时间，不叠加倍率，不占技能槽。

## 波次与三类首领

20 波，每波 30 秒，波内连续刷怪。150、330、480 秒出现阶段精英。第 600 秒随机生成以下一类巨型首领，清除剩余杂兵与旧弹体后开始决战。

- OMEGA 裂地重装：重锤 → 三线炮 → 重锤。高生命、较慢移动，重装机甲轮廓。
- PRISM 棱镜裁决者：三线炮 → 定点追猎 → 弹幕。高大型枪兵轮廓、棱镜浮标。
- TEMPEST 风暴主宰：弹幕 → 定点追猎 → 三线炮。悬浮翼体、八颗环绕核心，移动更快。

首领由项目已有原创机体扩展，具有不同模型轮廓、数值、配色、连招顺序。相对 v5 基础生命提高 30%，再乘首领类型系数。标准难度第 600 秒生命约为：重装 11123、棱镜 9672、风暴 10446。

每段攻击都有 1.55 秒独立预警，下一段于 2.15 秒后开始。红圈、红线落点锁定；绿色扇区指出弹幕缺口。半血出现核心过载特效，下轮连招增加第四段定点追猎；连招结束有 3.2 秒恢复间隙，狂暴后 2.2 秒。接触首领仍会受伤。

## 文件与开发

- src/game.js：游戏机制、卡池、研究、首领与特效。
- src/fullscreen.js：标准与 WebKit 全屏接口、F 快捷键、错误提示。
- src/actors.js、src/world.js：原有原创模型与地图，继续保留。
- src/icons.js、src/base.css、src/design.css、src/upgrade.css、src/v6.css：图标与界面。
- index.html、game.bundle.js、assets/models.js：离线运行入口与资源。
- vendor/、assets/、licenses/：Three.js、备用 CC0 模型、许可及来源。
- tests/、QA/、QA_REPORT.md：可重跑的检查脚本与本次实际结果。

开发者安装 Node.js 后，运行 npm install 与 npm run build。构建会生成离线脚本及 dist/ 静态发布目录。普通玩家不需要构建。

GitHub Pages 可直接发布此文件夹根目录或 dist/ 内容；同一份 HTML 可用于 Mac、Windows 与手机浏览器。全部引用为相对路径。
