# VOIDSTORM v5.0 · AEGIS-7 / 零界守望 v4

固定斜俯视镜头的单人科幻生存游戏。驾驶 AEGIS-7 在轨道设施中生存 10 分钟，并击败 OMEGA 核心。原创模型、分区地图、机库、战斗 HUD 和成长卡牌已重做，保留原有 12 武器、12 属性、成就与机库强化系统。

## 开始游戏

**电脑：完整解压文件夹，双击 `index.html`。不需要联网、不需要安装 Python 或 Node。**

- macOS 也可双击 `start_mac.command`；系统阻止脚本时直接打开 `index.html`。
- Windows 也可双击 `start_windows.bat`。
- 需要支持 WebGL 的现代浏览器。资源加载异常时会显示备用机体；WebGL 引擎失败会显示说明。
- 手机请用浏览器打开部署后的网页地址。手机文件管理器中的 HTML 预览不等同于完整浏览器，建议使用网页链接。

## 操作

- WASD / 方向键：移动，主武器自动射击。
- T：自动 / 手动瞄准；手动时由鼠标方向决定主武器弹道。
- E：棱镜壁垒，Lv3 解锁，初始 12 秒 CD。获得 35% 护盾，3 秒内拦截敌方弹体并向近敌释放脉冲。结束后反击：55 + 吸收伤害 × 0.65 基础伤害，再受伤害属性影响。吸收量最多记录一条最大生命。
- R：离子超载，Lv6 解锁，击杀充能至 100% 释放。展开 3.5 秒天罚阵列：追踪齐射、周期性轨道轰击，最后九米范围冲击。
- ESC 或右上暂停键：暂停。离开页面、切换窗口时自动暂停并清空移动输入。
- 升级三选一：鼠标点击、触屏点击或数字键 1/2/3。
- 手机自动显示左右摇杆、E/R 和自动瞄准切换。右摇杆操作时进入手动瞄准，可用左侧 AUTO/MANUAL 按钮切回自动。
- 声音按钮可静音。声音在点击开始之后启用，不会未经交互自动播放。

## 构筑与成长

最多同时装备 **5 个战斗技能（包含主武器）+ 6 种属性模块**。共有 12 种武器机制与 12 类属性。

同名卡升级原技能，不额外占槽。技能最高 Lv5；技能 Lv5 + 对应属性 Lv3 后有机会抽到进化卡。卡牌显示当前等级、升级效果及进化属性进度。满构筑后仍会提供三张不同的即时收益卡。

每次升级立即恢复 100% 最大生命。连续获得多级经验时，每一级都必须先完成一次三选一。晶体具有捕获、加速旋入、拖尾、缩小与吸收爆点。

## v5：进化指引与角色能力

进化图谱可从机库、战斗 HUD、升级选择界面打开；打开时暂停，返回时恢复原先状态。卡牌同时列出技能 5 格、属性 3 格进度，以及缺少的条件。满槽无法补齐的配方会明确标注。

采用无放回加权抽样：普通卡权重 1；已持有对应技能时，配套属性权重 1.25；已持有对应属性时，配套技能权重 1.25；条件齐全的进化卡权重 1.4。权重加成不叠加，也不代表固定 25%/40% 出现率；实际概率随可用卡池变化。每轮三张不同卡。

AEGIS-7 被动「自适应核心」不占技能槽：每 12 次击杀获得 10% 最大生命护盾，并在接下来 4 秒造成额外 15% 伤害。计数和剩余时间显示在 HUD。期间再次凑齐 12 次击杀会刷新持续时间，不叠加伤害倍率。

E 和被动添加护盾时，护盾总量上限为最大生命；R 保留额外 45% 护盾。E 的 3 秒结束后，未消耗的护盾仍保留，但不再拦截远处子弹或记录反击吸收量。

## 关卡与 OMEGA

一局 20 波，每波 30 秒，波内连续刷怪；随阶段加入枪兵、重装与更多混合敌群。150、330、480 秒出现阶段精英。第 600 秒进入 OMEGA 决战，清除剩余普通敌人与旧敌方弹体，停止刷普通怪。

标准难度 OMEGA 登场生命为 7440，模型宽度约为角色身高的三倍。半血进入核心狂暴，攻击间隔缩短，弹幕数量增多。

- 断层重锤：1.5 秒红圈预警，向圈外移动；落点锁定，不随 Boss 移动。
- 三线裁决：1.5 秒地面直线预警，走入线间空隙或远离射程。
- 围猎弹幕：1.5 秒预警，绿色扇区指出缺口；低速弹体可继续走位躲避。
- 身体接触仍造成伤害。危险区域边缘需为角色碰撞体留出距离。
