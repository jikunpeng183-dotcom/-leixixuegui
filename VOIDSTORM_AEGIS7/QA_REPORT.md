# VOIDSTORM v5.0 · 实际检查报告

日期：2026-09-05T02:23:22.502201+00:00。环境：macOS，Chrome 152.0.7977.77，Playwright。
桌面 1440×900；触屏模拟 390×844、844×390。

## 结果

**106 / 106 项检查通过。** 本版运行检查的 JavaScript / 控制台错误为 0。

- 50 项基础回归：真实键盘、触屏摇杆、暂停、模型、命中反馈、12 种武器、经验、升级满血、卡槽、离线入口。
- 30 项新版玩法：进化图谱、权重、E 护盾拦截反击、被动增伤、R 天罚、Boss 预警及安全位置。
- 9 项生命周期：120 次敌人生成死亡、600 秒关卡调度、Boss、胜利结算、再次开局。
- 8 项地图：四区连通、出生避障、地图事件与导航。
- 9 项新增触屏与资源检查：E/R 实际点按、图谱、横竖屏第三张卡选择、8 次技能循环释放、四方位弹幕缺口方向。

两万次固定种子加权抽取：配套技能 slicer 出现 2979 次，未配套 blade 出现 2432 次，比例 1.225；无重复卡。生产算法普通权重 1、配套 1.25、进化 1.4，均无放回抽样。该统计是当前测试卡池的结果，不是固定出卡概率。

标准难度第 600 秒 Boss HP 7440；预警内命中、提前移出圈、三线间空隙、弹幕绿色缺口均通过真实游戏伤害函数检查。绿色缺口图形还用四个不同方向与实际安全角度比对。Boss 死亡、结算、重开正常。

GPU 几何体检查：120 次敌人生成死亡后，清理基线 187，六轮均恢复到 187；触屏 E/R 连续 8 轮结束后，恢复到基线 101。未承诺任何设备的固定帧率。

file:// 离线入口：零 HTTP(S) 请求；7 个备用开源模型全部加载，原创 AEGIS-7 可见。所有依赖与素材在 ZIP 内，无需在线 CDN。

- src/game.js：加权卡池、进化图谱、E、R、被动、弹体、波次与 Boss。
- src/icons.js：30 个原创功能图标；src/upgrade.css：图谱、卡片配方、状态与触屏布局。
- index.html：新界面入口和技能说明；game.bundle.js：可离线运行的编译产物。
- package.json、README.md、THIRD_PARTY_ASSETS.md、CHANGELOG_v5.md、tests/、QA/。

保留 actors.js、world.js、原有模型资产、经验吸入与核心武器机制。第三方来源与许可证保持完整。

## 视觉检查

QA/screenshots 保存实际浏览器渲染：桌面卡牌、进化图谱、E、R、Boss 三线预警、手机竖屏及横屏。手机卡牌与图谱采用可滚动面板，已实际滚动并选取第三张卡。修正了手机按钮旧 E 名称以及提示层相互遮挡。

部分截图由受控游戏状态产生，以展示高等级技能和 Boss；地图总览仅在测试中临时调高镜头，正常战斗仍使用固定高度与角度。

## 仍存在的验证边界

- Windows 实机、Android 实机与 iPhone Safari 未现场验证；Chrome 触屏模拟不能等同所有设备验收。
- 600 秒关卡检查采用加速推进并控制角色存活，不是人工从零完整通关。后期数值平衡仍需要实际玩家试玩反馈。
- 低端手机的帧率与长时间温升尚未测量。
- 仅更新本地项目和桌面 ZIP，已有托管网页未同步本版。

```
node tests/qa.cjs
node tests/evolution.cjs
node tests/lifecycle.cjs
node tests/mapqa.cjs
node tests/mobile.cjs
```
